- Shared strict archive/request/proposal protocol, exact source matching and controlled revision merging.
- Immutable sources/history, cancellation/replacement, proposed items, unresolved conflicts, manual edits and pinning.
- Local Node.js CLI with atomic file writes, exclusive locks, revision/generation checks, Markdown and full JSON export/restore.

This is source preview work, not a published npm or stable release. Provider extraction evaluations, real host end-to-end compatibility, cross-platform CI execution and first-user trials remain pending. See [evidence](docs/evaluations/compatibility.md).
