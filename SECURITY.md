# Security

ThreadLatch is a preview. Source matching is not semantic verification. Local files and IndexedDB are unencrypted. Read [privacy boundaries](docs/PRIVACY.md) before using sensitive sources.

Please do not disclose exploitable vulnerabilities, private conversations or credentials in a public issue. GitHub **private vulnerability reporting is enabled**, verified on 2026-10-29. Use [Report a vulnerability](https://github.com/deAYS/threadlatch/security/advisories/new) to contact the repository maintainers privately. You can also find that action on the repository's [Security advisories](https://github.com/deAYS/threadlatch/security/advisories) page. No separate email address or guaranteed response time is claimed.

Reports should use synthetic data and include the affected version, environment, expected boundary and minimal reproduction. Relevant boundaries include source/reference validation, immutable history, revision races, file path/symlink containment, owned skill files, archive restoration and safe text rendering.
