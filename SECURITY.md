# Security

ThreadLatch is a preview. Source matching is not semantic verification. Local files and IndexedDB are unencrypted. Read [privacy boundaries](docs/PRIVACY.md) before using sensitive sources.

Please do not disclose exploitable vulnerabilities, private conversations or credentials in a public issue. GitHub's repository setting was checked on 2026-10-27: **private vulnerability reporting is disabled**. A separate private contact has not been established. Open only a minimal public issue asking the maintainer to establish a private reporting channel, without exploit details or sensitive data. Recheck the Security tab before sending a report in case the setting has changed. No email address or guaranteed response time is claimed.

Reports should use synthetic data and include the affected version, environment, expected boundary and minimal reproduction. Relevant boundaries include source/reference validation, immutable history, revision races, file path/symlink containment, owned skill files, archive restoration and safe text rendering.
